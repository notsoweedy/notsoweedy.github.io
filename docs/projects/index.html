Things I've built

Hackathon and side projects, newest first. Work projects are internal, so there’s no code to link to, but I’m always happy to talk about them.

Battery-aware power prioritization

Microsoft Garage Hackathon 2026, third place. You pick the one foreground app you care about. The tool gives it priority power and automatically hibernates idle background apps, delivering about 40% battery savings for the prioritized app.

An AI-Ops layer for ALIS

Microsoft, 2025. Added to ALIS, the lab platform I lead. It pairs a vector-search RAG pipeline for failure tracing with an LLM-based remediator, and cut mean time to repair by 40% across four mission-critical test suites: kstress, power state transition, HLK and BSP.

An MCP server for Azure DevOps

Microsoft Hackathon and Fix-Hack-Learn, 2025. A privacy-first Model Context Protocol server that lets local AI agents analyze ADO pipeline failures without any data leaving the machine.

Infrastructure ChatOps on Slack

VMware Global Borathon, 2023. A Slack-integrated deployment engine for provisioning and maintaining complex workloads through chat commands. It raised team productivity by 38%.

A swing-trading assistant

Ongoing, personal. A Python assistant for Indian equities that scans for technical setups and checks fundamentals and market regime. It runs risk guardrails, backtests and Monte Carlo simulations. It works in paper mode by default, and no order goes to the broker without my explicit approval. Writing it taught me a lot about designing agents that ask before they act.
